# v0.1.0-v20 — first-stage milestone

An experimental native Windows x64 port of Sin and Punishment: Star Successor.

**Reported working PC:** AMD Ryzen 5 5600, AMD Radeon RX 6750 XT, 16 GB DDR4, Windows 11. Driver, resolution and measured FPS were not recorded.

**Limitations:** only the first stage has been tested; audio is not 100% correct; Intel integrated graphics are currently unsupported; stable 60 FPS and full-game compatibility are not verified.

This pre-release publishes source, build helpers and documentation only. Supply your own supported USA R2VE01 game files and generate private translation/build output locally. No ISO/RVZ, extracted game assets, generated game-function C++, game-containing EXE or build cache is supplied.

See README.md and docs/BUILDING.md before attempting a build.
