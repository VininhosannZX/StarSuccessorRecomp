# Changelog

## v0.1.0-v20 — preserved experimental milestone

- Owner reported visible first-stage gameplay on Ryzen 5 5600 / Radeon RX 6750 XT / 16 GB DDR4 / Windows 11.
- Preserve the v20 renderer/runtime source and archived private executable identity.
- Keyboard/mouse input, graphics options and native image import are present.
- Audio remains incomplete; only the first stage has been tested.
- Intel integrated graphics are unsupported in this milestone.
- Stable 60 FPS, 4K performance and complete-game progression are unverified.
- Add source-only publication layout, build/input preparation helpers, troubleshooting, issue template and license notices.

Later renderer experiments are not included. This tag describes a checkpoint, not a full release.
